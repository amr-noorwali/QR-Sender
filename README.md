# QR Video Sender

تطبيق Flutter تجريبي ينقل فيديو محفوظًا بين جوالين عبر سلسلة رموز QR فقط.

## التشغيل

```sh
flutter pub get
flutter run
```

ثبّت التطبيق على جهازين. اختر **إرسال فيديو** على الأول و**استقبال فيديو**
على الثاني، ثم وجّه الكاميرا إلى شاشة المرسل حتى يكتمل شريط التقدم.

الحد الحالي 10 MB. تحفظ النسخة المستلمة في مجلد مستندات التطبيق وتفتح تلقائيًا.
